# Zaika House — Cinematic Restaurant Demo by 5Page

A premium animated café / restaurant demo website built with HTML, Tailwind CDN, custom CSS, JavaScript, GSAP and ScrollTrigger.

## Pages / Sections

- Premium preloader
- Sticky responsive navbar
- Cinematic hero section
- Quick info strip with animated counters
- Brand story section
- Signature dish cards
- Editorial menu board
- Daily specials / offers
- Experience section
- Visual gallery placeholders
- WhatsApp order builder
- Location section
- FAQ accordion
- Final CTA
- Footer with demo note

## How to use

Open `index.html` in your browser.

Before deploying, replace this placeholder in `index.html` and `script.js`:

```js
91XXXXXXXXXX
```

with the real WhatsApp number.

## Deployment

This is static and deployable on Netlify.

1. Create a folder with these files.
2. Drag and drop the folder to Netlify.
3. Or push to GitHub and connect the repository with Netlify.

## Tech

- HTML
- Tailwind CSS via CDN
- Custom CSS
- JavaScript
- GSAP
- ScrollTrigger
- No backend
- No paid APIs
